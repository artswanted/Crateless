Живой документ. Обновляется по мере продвижения.
Последнее обновление: 2026-09-19 (фаза 1 выполнена в ветке `crateless/phase-1-rebrand`).

## 1. Зачем

Armoury Crate 6.5.14 на ROG Zephyrus G16 (GA605WI) ведёт себя недетерминированно при
переключении режимов. Зафиксировано инструментально:

| Время | Что произошло |
|---|---|
| 17:38:34 | AC: план → Silent, режим Windows → Сбалансированный |
| 17:38:41 | AC: режим Windows → **Максимальная производительность** (никто не просил) |
| 17:20:13 | Турбо → Эффективность: план **сменился** |
| 17:38:55 | Турбо → Эффективность: план **не сменился**, при тех же условиях |

Источник отката — событие ID 51 (`Microsoft-Windows-UserModePowerService`), процесс
`ArmouryCrate.UserSessionHelper.exe`. Срабатывает через ~5–7 с после каждого переключения
и при старте службы, **для всех режимов**, включая Тихий и Эффективность.

Итог: «тихий» профиль работает поверх overlay «Максимальная производительность».
Плюс план Silent от сети держал минимальную частоту CPU на 80 %, Turbo — на 100 %.

Временное решение (задача планировщика `PowerOverlayGuard` + перетюненные планы) работает,
но это заплатка поверх закрытого софта, который ASUS переписывает каждый квартал.

**G-Helper делает это правильно нативно.** `app/Mode/PowerNative.cs`:

```csharp
public static string GetDefaultPowerMode(int mode)
{
    switch (mode)
    {
        case 1: return POWER_TURBO;    // ded574b5  Best Performance
        case 2: return POWER_SILENT;   // 961cc777  Best Power Efficiency
        case 3: return PLAN_HIGH_PERFORMANCE;
        default: return POWER_BALANCED; // 00000000 Balanced
    }
}
```

`SetPowerMode()` ставит план из конфига (`AppConfig.GetModeString("scheme")`), затем
overlay — один раз, и больше не трогает. Это ровно та карта, которую реализует наш сторож.

## 2. Цели

1. Портативная утилита управления ноутбуками ASUS ROG — одна экзешка, без служб и телеметрии.
2. Детерминированная связка «режим ↔ план питания ↔ Windows power mode».
3. Собственный интерфейс на WinForms.
4. Слой железа **не форкаем** — тянем из upstream, чтобы получать поддержку новых моделей даром.

## 3. Не цели

- Переписывать `AsusACPI.cs` / `Pawn/` / `Gpu/` — это ядро upstream.
- Linux-версия (пока).
- Закрывать исходники — GPL-3.0 остаётся.
- Гнаться за паритетом фич с Armoury Crate ради паритета.

---

## 4. Принятые решения

| Решение | Значение | Почему |
|---|---|---|
| Название | **Crateless** | без товарных знаков в имени, отсылка читается |
| Лицензия | GPL-3.0 | обязательна как производная работа |
| UI-стек | WinForms | единственный, что даёт одну экзешку без переписывания UI |
| C#-namespace | **остаётся `GHelper`** | переименование = вечные конфликты при мёрже upstream |
| AssemblyName | `Crateless` | меняем только имя сборки и exe |
| Сборка | framework-dependent single-file | как в upstream; self-contained — опционально |
| Целевой фреймворк | `net10.0-windows` | как в upstream; SDK 10.0.401 уже стоит |
| Тестовое железо | GA605WI / HX 370 / RTX 4070 | см. приложение A |

## Приложение C — итоги аудита E0 (2026-09-19)

Карта функций заполнена по коду: `Crateless-Design-Kit-Nebula-v2/docs/03_FEATURE_MAP_RU.csv`.
Ключевые факты для фазы 3:

- Режимы: `AsusACPI.PerformanceBalanced=0 / Turbo=1 / Silent=2 / FullSpeed=3 / Manual=4`;
  пользовательские профили `app/Mode/Modes.cs`, индексы 3..19, база через `mode_base_N`.
- GPU: `GPUModeEco=0 / Standard=1 / Ultimate=2`. «Optimized» — не аппаратный режим, а флаг
  `gpu_auto` (`GPUModeControl.AutoGPUMode`).
- Кривые вентиляторов: ровно 8 точек (16 байт), оси 20–110 °C / 0–100 %, `AsusFan {CPU, GPU, Mid, XGM}`,
  гистерезис 5 уровней. Отдельного «direct fan control» нет — `SetFanRange` только fallback.
- Обратное чтение лимитов: только `GPU_BASE`/`GPU_POWER` через `DeviceGet` и
  `ModeControl.ReadRyzenLimits()` (SMU). Для большинства `PPT_*` readback нет — в UI
  различать «команда принята» и «подтверждено».
- Нет в форке: compact mode, экспорт/импорт конфига, поэлементный список служб, GPU undervolt.
- Не покрыто дизайном: ROG Ally/Handheld (`app/Ally`, `app/Handheld.cs`), гарнитуры,
  скрытые переключатели `app/Extra.cs` (E/P-ядра, VRAM/APU, ASPM, boot sound, Keystone, ACPI debug).

## Фаза 3 (уточнение 2026-09-19) — целевой состав экранов

Ориентир по композиции и функциям — Armoury Crate 6.5 на GA605WI (12 скриншотов пользователя).
Берём компоновку, плотность и набор функций; стиль остаётся Nebula, товарные знаки ASUS/ROG не копируем.
Статус: ✅ есть в форке · 🔧 есть бэкенд, нужен экран · 🆕 бэкенда нет, дописываем сами · ⛔ не делаем.

### Оболочка
- Sidebar с подписями и группами (Главная, Устройства, Подсветка, Профили, Дисплей, Настройки), сворачивается до иконок. 🔧
- Заголовок раздела + вкладки внутри раздела (как «Настройки системы → Конфигурация / ОЗУ / ГП / Горячие клавиши / Подсветка / Звук»). 🔧
- Переключатель компактного режима в правом верхнем углу. 🔧 (компактное окно 440×700 из кита)

### Главная
- Слева: рендер устройства, модель, строка CPU / GPU (+ объём VRAM), список подключённых устройств с картинками. 🔧
  Рендер: общий из кита + свой файл `%APPDATA%\Crateless\hero.png` при наличии. Официальные рендеры ASUS ⛔.
- Блок «Процессор»: частота, использование, температура — 🔧 (частота через PerformanceCounter «% Processor Performance»); частота памяти, напряжение — 🆕 (нужен свой SMU/WMI-ридер) либо «—».
- Блок «Графика»: частота, использование, температура, Max TGP — 🔧 (NVAPI уже в форке); напряжение, частота памяти — 🆕.
- Блок «Вентилятор»: CPU / GPU / System RPM ✅; «уровень шума» ⛔ (у ASUS расчётная величина).
- Блок «Память»: ОЗУ ✅; накопитель (занято / всего) 🔧 (DriveInfo).
- Ряд режимов внизу: Windows / Тихий / Эффективность / Турбо / Ручная с иконками ✅ (Modes + custom).

### Устройства
- Плитки: ноутбук + периферия ASUS (мыши, клавиатуры, гарнитуры) ✅ бэкенд `Peripherals/`, экран 🔧.
- Клик по ноутбуку → «Настройки системы» с вкладками:
  - **Конфигурация системы**: плитки Win-клавиша, Fn-lock, Тачпад, Звук при загрузке, Modern Standby-помощник, Панель энергосбережения (авто-Гц от батареи), Синхронизация режимов питания. Все ✅ в Extra/Settings, экран 🔧.
  - **ОЗУ**: объём для iGPU (VRAM/APU) ✅ бэкенд `SetAPUMem`; список процессов для выгрузки 🆕.
  - **Производительность ГП**: 4 плитки режимов GPU с описанием ✅; список процессов на dGPU + «Остановить все» ✅ (`KillGPUApps`), список 🔧.
  - **Горячие клавиши**: схема M1–M4 + выпадающие действия ✅ (Extra.SetKeyCombo), экран с клавишами 🔧.
  - **Подсветка**: плитки эффектов, темп, яркость ✅ (Aura), экран 🔧.
  - **Звук / микрофон**: режимы шумоподавления ⛔ (это Realtek/ASUS DSP, вне ACPI) — оставить ссылку в Windows.
- Aura Sync: синхронизация подсветки между устройствами ✅ (`*_aura_sync`), «Обои AURA», Hue ⛔.

### Настройки дисплея
- **GameVisual**: плитки Default / Racing / Scenery / RTS / FPS / Cinema / Eyecare / Vivid / E-book с иконками ✅ (`VisualControl.GetVisualModes`); цветовое пространство ✅ (`GetGamutModes`); цветовая температура ✅ (`color_temp`); OSD/Fn+V 🔧.
- **Калибровка цвета** ⛔ (нужен колориметр и проприетарный движок), оставить «Установить ICC-профили» ✅.
- **Настройки OLED**: автоскрытие панели задач 🆕 (реестр), прозрачность панели задач 🆕 (реестр), Flicker-Free Dimming ✅ (`SetBrightness`), «Целевой режим» (dimming неактивных окон) ⛔.

### Порядок работ
1. Страницы Батарея, Экран (в работе) → Подсветка → Устройства/Периферия → Настройки.
2. Перекомпоновка Главной под 2×2 блока + ряд режимов + устройства.
3. Sidebar с подписями и вкладки внутри разделов; компактный режим.
4. «Настройки системы» с вкладками; замена встроенных старых форм Fans/Extra на новые страницы.
5. 🆕-пункты по отдельности после того, как всё ✅/🔧 перенесено.
